구성 방식

마지막 레퍼런스 버전처럼 왼쪽에는 템플릿 스위처, 오른쪽에는 모바일 디바이스 프리뷰 구조를 유지했습니다. 안쪽 템플릿만 10개로 확장한 형태예요.

모든 템플릿에 공통으로 초대문, 갤러리, 오시는 길, RSVP, 주소 복사, 캘린더 저장을 넣었습니다.

실서비스에 붙일 때

템플릿 데이터화이름, 날짜, 장소, 문구, 사진 URL만 JSON으로 빼기
사진 업로드 연동외부 URL 대신 S3/Azure Blob 경로로 교체
RSVP API 연결현재는 데모 저장, 실제로는 폼 submit 연동
브랜드화상단 로고와 색상 시스템을 서비스 톤에 맞게 조정
복사되었습니다.
